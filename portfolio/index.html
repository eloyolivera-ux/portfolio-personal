CASO DE ESTUDIO / 2026

Mesa de Ayuda

Aplicación web académica para gestionar clientes y solicitudes de soporte técnico.

01 / Problema

Los tickets y datos de clientes necesitan organizarse y consultarse mediante una interfaz clara. El desafío consistió en conectar un sitio web con operaciones de un servicio de soporte.

02 / Proceso

Trabajé sobre formularios, validación de datos, solicitudes HTTP y pruebas de endpoints. La interfaz se comunica con un backend implementado con Node.js y Express.

03 / Solución

Se implementaron flujos de registro de clientes y consulta de tickets mediante una API. Se prestó atención a los mensajes de respuesta y al intercambio de datos entre navegador y servidor.

04 / Resultado y aprendizajes

Proyecto académico para practicar integración frontend-backend, manejo de peticiones HTTP y validaciones. Una mejora futura sería profundizar pruebas automatizadas y accesibilidad de formularios.
